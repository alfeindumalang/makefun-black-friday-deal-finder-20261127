DealSleuth — a Black Friday and Cyber Monday deal finder with 26 real deals, found and checked by an agent on Black Friday morning, 27 November 2026. Every deal shows its product, store, store link, sale price, usual price, discount, dollars saved, an honest verdict (TRUE LOW, STRONG PRICE, ROUTINE SALE, or SMALL CUT, with the evidence for it), and when and where its price was checked. Search and filters by category, store, and discount work; the board sorts by biggest discount, biggest saving, price, or name. It runs entirely from static files, with no network request, on desktop and on a phone.

## Run it

```sh
node serve.ts
# app/ is on http://localhost:8080
```

## Hand it in

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
